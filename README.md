# Wine · Class

本地预览：在此目录运行 `npm run dev`，默认地址 http://127.0.0.1:5189。启动前确认端口未被其他项目占用。

`index.html`：A/B/C 结构和可编辑正文。
`style.css`：响应式静态样式。
`app.js`：作品与人群内容、作品弹窗、滚动动画。
`assets/`：独立 WebP 素材。

动画参数位于 app.js 底部：`course-expand` 控制 B 从右下方放大，`black-reveal` 控制 C 在揭露期间固定。模块按真实内容自然排版，不限制为一屏。支持反向滚动及系统减少动态效果设置。

每个文字块、标签和图形都有独立 DOM。`data-module` 标识模块，`data-art` 标识可独立运动的图形，`data-reveal` 是当前轻量文字出现效果的入口。需要逐行效果时可继续在相应文字块内拆分 span。

视觉待补充：准确字体文件、清晰的原始反馈截图、独立白色字标和价格区域笑脸。当前字标通过现有素材派生，正文根据长稿录入，人群小字需与可复制终稿核对。主页/作品/关于导航目前指向当前 Class 页对应内容，未虚构其他页面。

元素依次入场：app.js 的 `elementMotion` 使用统一 GSAP timeline，按当前可见元素从上到下、从左到右依次播放，起始间隔 0.14 秒，时长 0.75 秒，`power3.out` 缓动。标题和正文上移 24px，图形上移 32px，不含弹性、反弹或缩放。

视觉元素视差：易拉罐、阶梯、星形与笑脸徽章、字标保留不同视差深度，手机幅度为桌面的 55%。视差使用独立 CSS translate，入场使用 GSAP transform，保持原始布局尺寸和 A/B/C 转场。C 的元素等待实际揭露后入场；减少动态效果设置下直接显示静态内容。
